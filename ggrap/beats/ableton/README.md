# Sending GGRap new instruments from Ableton

The app turns any instrument into a playable GGRap instrument if it gets one recording of the
instrument playing notes in a known order. These MIDI files play that order for you.

## Melodic instruments (keys, pads, strings, plucks, brass, flutes...)

1. Drag `GGRap-instrument-notes.mid` onto a MIDI track that has the instrument loaded.
2. Set the project tempo to **120 BPM** (the file plays C1, D#1, F#1, A1 ... up to C7: 2 seconds per note, 1 second of silence between notes).
3. Turn off effects with long tails (big reverb or delay), so each note ends during the silence.
4. **File → Export Audio/Video**: WAV, 44.1 kHz, 24-bit, only that track.
5. Name the file after the instrument, for example `Rhodes.wav`, `Strings Warm.wav`.

## 808 and bass

Same steps with `GGRap-808-notes.mid` (C0 up to C3, 3 seconds per note).
Name it with the word 808 or Bass, for example `808 Deep.wav`.

## Drums and one-shots

Export each hit as its own short WAV. Put the type first in the name so the app knows what it is:
`kick_...`, `snare_...`, `clap_...`, `hat_...`, `openhat_...`, `perc_...`, `rim_...`, `tom_...`, `fx_...`.

## Sending

Put everything in one folder, zip it, and attach the zip in the chat.

## Rights

Only send sounds you are allowed to put inside an app that other people use. Sounds that come with Ableton
and most sample packs may be used in **your own songs**, but usually not handed out **as sounds inside an
app**. For your own testing that is fine. For the public app we need sounds you made yourself, CC0 sounds,
or packs whose license allows app use. Tell me where each sound came from and I will keep track.
